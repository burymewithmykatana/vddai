# Product Documentation

Use these documents to define what VDDAI should solve and how a customer pilot
will be evaluated. Product hypotheses are not customer evidence.

| Document | Status | Purpose |
|---|---|---|
| [`product-definition.md`](product-definition.md) | Current | Product identity and v0.1 boundary |
| [`problem-statement.md`](problem-statement.md) | Draft | Problem and impact hypotheses requiring validation |
| [`customer-discovery.md`](customer-discovery.md) | Draft | Interview plan and evidence log |
| [`target-markets.md`](target-markets.md) | Current hypothesis | Market-selection criteria and candidates |
| [`pilot-offer.md`](pilot-offer.md) | Current | Feasibility-pilot scope and deliverables |
| [`success-metrics.md`](success-metrics.md) | Draft | Technical, operational, and commercial decision measures |

Do not represent MVTec benchmark performance as customer validation. Record
interview and pilot evidence explicitly before promoting a hypothesis to a
validated product claim.
