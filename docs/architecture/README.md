# Architecture Documentation

Architecture documents describe the current system boundary. Durable changes
to that boundary require an ADR under [`../decisions/`](../decisions/README.md).

- [`system-requirements.md`](system-requirements.md): current functional,
  security, ML-integrity, persistence, and operational requirements.
- [`../engineering/data-lineage.md`](../engineering/data-lineage.md): current
  offline and online data-lineage flow.
- [`../../AGENTS.md`](../../AGENTS.md): operational constraints for coding
  agents.

Executable contracts and accepted ADRs take precedence when this material
becomes stale.
